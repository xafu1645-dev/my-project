# ระบบ QR Code จัดการโควต้าและยืนยันสิทธิ์ลูกค้า

เว็บภาษาไทยสำหรับเพิ่ม/แก้ไขข้อมูลลูกค้า สร้าง QR Code เฉพาะราย สแกนเพื่อตรวจสอบสิทธิ์ แสดงสลิปพิมพ์หรือบันทึก PDF แนบใบจอง จัดการผู้ใช้ และดูบันทึกกิจกรรม

## ฟังก์ชัน
- เข้าสู่ระบบเจ้าหน้าที่/ผู้ดูแล รหัสผ่านเก็บแบบ bcrypt
- ฐานข้อมูล SQLite บนเซิร์ฟเวอร์
- ชื่อ นามสกุล เลขโควต้า เลขใบจอง วันที่ โครงการ หมายเหตุ และสถานะสิทธิ์
- ป้องกันเลขโควต้าซ้ำ, QR ใช้ token สุ่มไม่บรรจุข้อมูลส่วนบุคคลโดยตรง
- หน้าตรวจสอบสาธารณะ, สแกนผ่านกล้อง (ต้อง HTTPS ยกเว้น localhost), พิมพ์สลิป/บันทึก PDF
- แนบไฟล์ใบจอง PDF/JPG/PNG/WEBP สูงสุด 8 MB; ไฟล์อยู่ในโฟลเดอร์ส่วนตัว
- ผู้ดูแลสร้าง/ปิดบัญชี ดู audit log และลบข้อมูลลูกค้าได้
- ส่งออก CSV

## ติดตั้ง
ต้องมี Node.js 20+
1. เข้าโฟลเดอร์ `qr-system`
2. รัน `npm install`
3. คัดลอก `.env.example` เป็น `.env`
4. ตั้ง `SESSION_SECRET` เป็นค่าสุ่มยาวอย่างน้อย 32 ตัวอักษร และ `ADMIN_PASSWORD` อย่างน้อย 12 ตัวอักษร
5. ตั้ง `PUBLIC_BASE_URL=http://localhost:3000`
6. รัน `npm start` แล้วเปิด `http://localhost:3000`

บัญชีผู้ดูแลจะถูกสร้างตอนเริ่มระบบครั้งแรกเมื่อฐานข้อมูลยังไม่มีผู้ใช้และตั้งรหัสผ่านเริ่มต้นอย่างปลอดภัยใน `.env` เท่านั้น หากไม่ตั้งค่า ระบบจะไม่สร้างบัญชีเริ่มต้น

## Deploy
ต้องนำไป deploy บนโฮสต์ Node.js ที่รองรับ persistent storage; ตั้ง `NODE_ENV=production`, `SESSION_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `PUBLIC_BASE_URL=https://โดเมนของคุณ`; เปิด HTTPS และเก็บ `data.sqlite`, `sessions.sqlite`, `private_uploads/` ไว้ในพื้นที่ถาวรพร้อมสำรองข้อมูลเข้ารหัสเป็นประจำ. การ push ขึ้น GitHub ไม่ได้ทำให้เว็บไซต์ออนไลน์เอง.

## ข้อควรทราบ
- QR สาธารณะเปิดเผยชื่อ นามสกุล เลขโควต้า และข้อมูลใบจองบางส่วน โปรดควบคุมการแจกจ่าย QR และแจ้งผู้เกี่ยวข้อง
- สถานะอนุมัติเป็นข้อมูลที่เจ้าหน้าที่ตั้งในระบบ ไม่ได้ตรวจสิทธิ์กับหน่วยงานภายนอกโดยอัตโนมัติ
- ก่อนใช้ข้อมูลจริง ให้ทดสอบสิทธิ์ การสำรอง/กู้คืน HTTPS และนโยบาย PDPA
